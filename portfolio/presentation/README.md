# Portfolio technique — Zokoichi

Ce portfolio présente des réalisations techniques issues de travaux réellement réalisés et conservés sous forme de code, workflows, scripts, tests et artefacts.

## Méthode de preuve

- **P1 — Structure prouvée** : présence et architecture observables dans les artefacts.
- **P2 — Comportement technique observable** : paramètres ou code permettant d'établir une opération réalisée.
- **P3 — Validation expérimentale** : test ou résultat d'exécution conservé.
- **P4 — Résultat externe** : vente, revenu, client, audience ou performance commerciale mesurée.

Aucun résultat commercial n'est déclaré sans preuve.
